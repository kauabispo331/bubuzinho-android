# Bubuzinho para Android

Jogo original de bichinho virtual, inspirado no gênero de pets virtuais.

## Conteúdo

- `bubuzinho-apk.zip`: projeto completo para abrir no Android Studio e gerar o APK.
- O jogo funciona sem internet e salva o progresso no aparelho.

## Gerar o APK

1. Baixe `bubuzinho-apk.zip` e extraia o conteúdo.
2. Abra a pasta `bubuzinho-apk` no Android Studio.
3. Aguarde a sincronização do Gradle.
4. Use **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
